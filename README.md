🎨 Toonify Application

## Overview
Toonify is an AI-powered image transformation application built using Python and Streamlit. It allows users to upload images and apply different artistic effects such as Cartoon, Sketch, Pencil Sketch, and Oil Painting.

## Features
- User Login & Registration
- Image Upload
- Cartoon & Artistic Filters
- Brightness, Contrast & Sharpness Controls
- Original vs Transformed Image Comparison

## Technologies Used
- Python
- Streamlit
- OpenCV
- Pillow
- NumPy

## Run the Project

```bash
pip install -r requirements.txt
streamlit run app.py
```
